## About the site

This site uses this Hugo static site generator, and is hosted on Cloudflare Pages/Workers.

Search uses [Pagefind](https://pagefind.app/) (which builds a relatively tiny chunked index from the static contents at build time and has a minimal network footprint).

I am a big fan of this setup; some day I'll move it on-prem (or not - my hosting is presently free, it never goes down, and I'd probably be behind Cloudflare anyway).

The theme I'm using is [my fork of](https://github.com/hpst3r/etch) [Lukas Joswiak's etch](https://github.com/LukasJoswiak/etch).

The fork is available [on GitHub here](https://github.com/hpst3r/etch).
